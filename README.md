# L’Heure de Brume

Русскоязычный сайт парфюмерного дома L’Heure de Brume. В коллекции 18 ароматов. У каждого есть отдельная страница с фотографией флакона, описанием и пирамидой нот.

## Что есть на сайте

- **Коллекция** с карточками ароматов и описанием того, как раскрывается каждая композиция.
- **Подбор ароматов.** В базовом режиме можно выбрать знакомые ноты, например ирис или мускус. В расширенном — задать ноты отдельно для верхнего, среднего и базового уровней пирамиды. В обоих режимах выдача учитывает все выбранные условия.
- **Мои пробники.** Ароматы можно добавить в подборку или удалить из неё. Выбор хранится в браузере и сохраняется после перезагрузки.
- **Журнал** со статьями о парфюмерии и историей основания дома.

## Локальный запуск

Понадобится Node.js 20 или новее. Устанавливать зависимости не нужно. Выполните команды из корня репозитория:

```bash
node build.mjs
node serve.mjs
```

Затем откройте [локальный сайт](http://127.0.0.1:4173/).

Если в системе есть npm, обе команды можно заменить на `npm run dev`.

## Сборка

```bash
node build.mjs
```

Готовые страницы и статические файлы появятся в `dist/`. Чтобы посмотреть уже собранную версию, запустите `node serve.mjs`.

## Стек и структура

HTML, CSS и JavaScript. Node.js генерирует отдельный HTML-файл для каждой страницы. Подбор ароматов и сохранение пробников работают в браузере.

| Путь | Назначение |
| --- | --- |
| `scents.mjs` | Названия, описания и пирамиды нот |
| `build.mjs` | Шаблоны страниц, статьи журнала и сборка |
| `photos/` | Фотографии флаконов |
| `style.css` | Общие стили и адаптивная вёрстка |
| `site.js` | Подбор по нотам и сохранение пробников |
| `serve.mjs` | Локальный сервер |
